How it works

    

      
Small models guess the value
A fine-tuned 1.5B tester finds good inputs but often writes the wrong expected output, so its test fails on both programs.

      
Execution answers instead
Implementations written from the specification are run on the same input. Their majority output replaces the guess.

      
Every number is checked
Tests are always executed on both programs. Validation runs were pre-registered and run once.

    

    

      
Tester
The model that writes the tests (base 1.5B, our fine-tuned A@431, or UTGen-1.5B).

      
Voters
Eight implementations written from the specification and signature only.

      
Valid kill
Passes on the correct program and fails, errors or times out on the faulty one.

      
Kill@k
Share of targets with a valid kill among the first k tests.
